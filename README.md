# Telegram-бот для автоматизации локальной службы доставки (г. Костанай)

Асинхронный Telegram-бот на Python для координации работы клиентов и курьеров. Проект разработан как MVP (минимально рабочий продукт) для локального сервиса доставки посылок из маркетплейсов (Ozon, Wildberries, Temu) до двери клиента.

## 🚀 Основной функционал

- **Интерфейс клиента:** Пошаговый сбор данных о заказе (ПВЗ, скриншот QR-кода, адрес доставки, телефон) с использованием конечных автоматов (FSM). Выбор удобного способа оплаты (Kaspi / Наличные).
- **Интерфейс курьеров:** Публикация активных заказов в закрытую группу курьеров в виде интерактивных карточек. Кнопка «Взять заказ» с защитой от одновременного перехвата заказа разными курьерами.
- **Безопасность:** Проверка прав курьера (изменить статус заказа на «Доставлен» может только тот, кто его взял), полная параметризация SQL-запросов для защиты от инъекций.

## 🛠 Стек технологий

- **Язык:** Python 3.11+
- **Фреймворк:** Aiogram 3.x (Асинхронная библиотека для Telegram API)
- **База данных:** SQLite (через асинхронный драйвер `aiosqlite`)
- **Управление окружением:** `python-dotenv`

## 📦 Схема базы данных (SQLite)
Таблица `orders` хранит данные о клиенте, параметры доставки, выбранный тип оплаты, текущий статус заказа (`Новый`, `В работе`, `Доставлен`), а также ID и username закрепившегося курьера.

## ⚙️ Инструкция по локальному запуску

1. Склонируйте репозиторий.
2. Создайте виртуальное окружение и установите зависимости: `pip install -r requirements.txt`.
3. Создайте файл `.env` на основе `.env.example` и заполните ваши токена бота и ID рабочей группы.
4. Запустите проект: `python main.py`.
